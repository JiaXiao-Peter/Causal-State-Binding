# Excluded Materials

The release excludes:

- private API keys, provider credentials, shell history, and local config files;
- `configs/providers.local.yaml` and other machine-specific runtime paths;
- raw model/API traces when compact source-data tables support the manuscript
  claim;
- third-party repository checkouts and source trees that should be fetched from
  their upstream projects;
- local review strategy notes, submission-system metadata, and unrelated older
  project materials.
