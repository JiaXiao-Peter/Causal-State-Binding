# Research materials

The [versioned research package](https://github.com/JiaXiao-Peter/Causal-State-Binding/raw/refs/heads/main/research/CSB_research_materials_20261001.zip) supplies analysis-ready materials for the current paper. Its local submission equivalent is named `reviewer_research_package.zip`; the bytes are identical.

| Scientific question | Included materials |
|---|---|
| How do controlled state manipulations affect action responses? | Controlled-action summaries, component and source strata, baseline replication summaries and plotted values. |
| Does agent-written state contribute to execution? | Core execution outcomes, task and mechanism analyses, restoration and information-access controls, and the recorded checkpoint example. |
| What is the role of memory content beyond transaction identifiers? | The fixed 128-task verification, condition-level observations and paired summaries, with development records kept distinct. |
| Does substituted content redirect action? | Original-target and replacement-target scoring of the same saved actions. |
| How well do diagnostic features predict localization success? | Development features and frozen estimators, cohort membership/exclusions, 3,200 independent frozen predictions, scores, saved paired draws, calibration and resource summaries. |
| How are visible outputs assessed? | Anonymized individual annotation records, scoring summaries and agreement calculations. |

`package_manifest.json` records the hashes of all 290 payload files; the ZIP also contains the manifest itself. The scientific records and executable code are the same observations and analysis inputs used in the paper. See [reproduction instructions](../REPRODUCE.md) and the extracted package's README for exact commands and paths.

The public package supports the reported analyses and figure reconstruction. Full provider-call archives, model weights and environment snapshots are separate from this compact analysis-ready distribution. Third-party benchmark records remain subject to their original terms.
